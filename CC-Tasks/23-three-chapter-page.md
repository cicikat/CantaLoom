# 工单 23：首页三个视觉章节与竖屏版式

Owner：Toge（toge / Frontend / UX）。状态：页面实现与 Mock 回归完成，待 toge 肉眼/真机核对（2026-11-07）。
范围：`src/App.tsx`、`src/components/HeroTitle.tsx`、`src/components/ChapterBridge.tsx`、`src/chapters.css`、`src/patchlab.css` 中被替换的 PV 弹层/结尾横幅样式，以及受影响的前端页面测试。
依赖：toge 本轮明确要求把单页重构为三个可连续滚动的视觉章节，并顺带调整竖屏与过紧凑区域。此工单不授权修改后端、音乐算法、共享契约、`src/visual.ts` 画面或导出链路。

## 设计要求（toge 原话要点）

- 第一章：「敲一下。变成一首歌！」与插图；元素交替出现、带音乐节奏感；「变成一首歌！」逐字从旋转的十字星星里弹出，向右溅出小碎片再回到稳定（星星负责旋转，文字负责弹出）。
- 第二章：向上的一圈圈圆形过渡，全屏纯色显示 `Music Blocks`，停留一会再进入音乐工作台。
- 第三章：MV 页面，MV 预览包含在其中。
- 竖屏和几处同页过紧凑的区域顺带调整。

## 应做与验收

- [x] 第一章占满首屏；左右元素按固定节拍交替入场，「敲一下。」敲章式落下，「变成一首歌！」逐字由旋转星星弹出并向右溅出碎片，下划线最后画出；系统「减少动态效果」时直接显示静态版。
- [x] 第二章开头为滚动驱动的过渡：五个彩色大圆依次向上升起盖住首屏，最后一圈与工作台同为淡紫色，`Music Blocks` 在纯色页停留约一屏滚动距离，随后工作台在同色背景上接续出现；过渡层只做装饰，对读屏隐藏，不拦截首屏操作。
- [x] 第三章为深色「放映厅」：原 PV 弹层改为页面内章节 `#pv`（区域名「歌词 PV」），包含画面预览、播放、独立进度条、字幕样式、换色、导出 MP4 与说明；导航「PV ✦」滚动到该章。导出作品弹层保持不变。
- [x] 竖屏与紧凑区域：手机导航不再折行、歌词卡在窄屏改单列、首屏插图与贴纸在单列时保持成组、章节上下留白加大、MV 页在手机上纵向排列；390px 无横向滚动。
- [x] 更新受影响的 Mock / 真实模式页面测试（PV 从弹层改为章节、首屏与积木位置的新几何关系）。
- [ ] toge 在电脑、手机实际滚动核对动效节奏、过渡停留时长与配色；如需调整节拍或停留距离，改 `src/chapters.css` 顶部的 `--beat`。第二章开头的圆形过渡（原 ChapterBridge）已由[工单 29](29-five-chapter-scroll-transitions.md)的幕布转场取代，过渡手感在工单 29 核对。
