## 总体要求

从当前自动生成短歌的系统，升级为支持人工精细调声、局部重唱、长歌曲编曲、模型路由及专业混音的音乐制作引擎。

执行前阅读 `AGENTS.md`、`docs/ARCHITECTURE.md`、`docs/TEAM_WORKFLOW.md`，检查最新 main 和现有工单。

**开发原则：**

- 只修改后端、音乐核心、共享契约和必要的跨层音频适配代码。
- 不直接修改 Toge 负责的 React 页面、UI、Mock。
- 优先扩展已有接口，避免建立重复 API。
- 所有新接口提供 Zod Schema、TS 类型、请求/响应示例与错误语义。
- 不使用硬编码歌词、固定音符或伪造 WAV 替代真实生成。
- 分阶段开发，每阶段独立测试、提交与验收，未经确认不连续实施后续阶段。
- 不在本工单中进行无关架构重构。

### P0 交接 Toge（接口、Schema、示例与语义）

本轮**无新 HTTP 端点**；单句重唱/改词/调音复用现有接口与共享函数，跨层触碰 `src/audio.ts`、`src/audio-mix.ts`、`src/features/singing/qixuan.ts`（工单范围），PR 需 toge review。

| 能力 | 入口 |
|---|---|
| 改词（保留旋律/重新作曲） | `setLyricText(project,lineId,text,{keepMelody})`（src/melody.ts）；重新作曲后接 `melodyRequest` → `api.melody` → `applyMelodyDraft`（targetIds=[lineId]） |
| 编辑音高/起点/长度 | `editPhraseNotes(project,lineId,notes)`（src/melody.ts），整数组提交、原子应用 |
| Pitch 曲线调教 | `setPhrasePerformance(project,lineId,{mode:'manual',overrides:[{index,origin:'manual',pitch:[...]}]})`；Schema：`pitchPointSchema`/`pitchCurveSchema`（shared/contracts/melody.mjs + .d.mts 的 `PitchPoint`） |
| 单句重唱 | 沿用 `generateLine`/`applyVocalResult`；渲染请求与响应契约不变 |
| 恢复历史演唱 | `restoreVocalAsset(project,lineId,index)`（src/features/singing/qixuan.ts） |

1. 请求/响应示例：Pitch 覆盖片段 `{index:0,origin:'manual',pitch:[{x:-80,y:-60,shape:'io'},{x:30,y:0,shape:'io'},{x:200,y:40,shape:'l'}]}`；`POST /api/singing/qixuan/render` 请求体在既有 `performance` 字段内携带，响应契约不变（新 take 新 audioUrl）。
2. 字段含义：x=相对音符起点的毫秒（负值为先入）、y=十分之一半音整数（±1200）、shape 为 USTX 插值；2–64 个按 x 严格递增的点。提供时替换该音符自动过渡点；删除 pitch 字段即恢复自动。
3. 状态说明：歌词/音符/锁定在生成期间变化 → applyVocalResult 抛错且工程保留；渲染失败 → 旧资产保留；restoreVocalAsset 在依赖或 runner 不匹配时抛「不能恢复」；editPhraseNotes/setLyricText 全部先校验后替换，失败工程不变。
4. 缓存失效：仅本句歌词/音符/Performance（含 pitch）变化使本句演唱依赖失效；兄弟句与器乐缓存不变；重新作曲（notes 清空）同时清除该句按旧索引的 overrides。
5. Mock 与测试证据：Mock 当前不返回 pitch（扩展归 toge，夹具须显式 mock 标记）；真实证据见 tests/p0-tuning.test.ts、tests/qixuan-real.test.mjs、tests/browser/p0-resing.spec.ts 与迭代日志 2026-11-07 条目。

## P1 · 逐音素与高级人声表现

- [x] 研究换气、气声、声线张力等效果的真实实现方式。气声＝brec 曲线原生支持（真实 WAV 已验证）；换气声无呼吸采样可合成，不支持；声线张力 tenc 声库无 embed，不支持；两者不做假开关。
- [x] 区分原生支持、可通过音频处理近似、不支持的效果。`GET /api/singing/qixuan` 新增 `capabilities`（从声库 dsconfig 与声码器配置实测解析，不硬编码）；INTERFACES/ARCHITECTURE 如实标注三类边界。

### P1 交接 Toge（接口、Schema、示例与语义）

本轮**无新 HTTP 端点**；调教数据沿用 `lyric.performance` 与既有渲染/状态接口。跨层未触碰 Toge 文件（UI/Hook/Mock 均未改），PR 需 toge review 契约与文档。

| 能力 | 入口 |
|---|---|
| 能力查询 | `GET /api/singing/qixuan` → `capabilities`（curves 八项布尔 / phonemeOverride / unsupported），从声库配置实测解析；UI 以此决定可用调教项 |
| 逐音素时序/发音 | `setPhrasePerformance(project,lineId,{mode:'manual',overrides:[{index,origin:'manual',phonemes:[...]}]})`；音素索引参照渲染响应 `phonemes` |
| 颤音全参 | `overrides[]` 的 vibratoLength/Period/In/Out/Drift/VolLink；缺省保持自动形态 |
| 力度/句尾衰减/收音 | `performance.dynCurve`（句首相对毫秒 × 0.1 dB，替换自动 DYN） |
| 气声/发声/声线/速度/音高 | `performance.curves`（brec/voic/genc/velc/pexp/shfc，句首相对毫秒 × 描述符整数） |

1. 请求/响应示例：音素覆盖 `{index:0,origin:'manual',phonemes:[{index:1,offsetMs:80},{index:2,phoneme:'zh/ang'}]}`；表现曲线 `curves:[{abbr:'brec',points:[{x:0,y:80},{x:2000,y:-40},{x:3900,y:60}]}]`；渲染响应新增可选 `phonemes:['zh/h','zh/ai',...]`。
2. 字段含义：音素 index＝本音符音素化结果序号（0–15，每音符 ≤8 条、位置唯一）；offsetMs ±300 按 BPM 换算 tick；phoneme 须含语言前缀（如 zh/ang）且在声库词表内，否则渲染前报错「音素不在绮萱词表中」。曲线 x＝句首相对毫秒（0–30000）、2–64 个严格递增点，覆盖范围外回落引擎默认（brec/genc/shfc=0、voic/velc/pexp=100、dyn=0）；dynCurve y 为 0.1 dB（−240–120）。
3. 状态说明：非法音素/越界曲线/颤音淡入淡出合计 >100 → setPhrasePerformance 或渲染明确抛错，工程与旧资产不变；改词重新作曲仍清除旧索引 overrides（含 phonemes）；保留旋律的改词保留 overrides，但音素语义可能随新发音变化，需用户确认。
4. 缓存失效：全部新字段随 resolvePerformance 进入演唱依赖与服务端缓存键，仅本句失效；不含新字段的工程缓存键与 v0.3.3 逐字节一致（单元回归锁定）。
5. Mock 与测试证据：Mock 不返回 capabilities/phonemes/新字段（扩展归 toge，夹具须显式 mock 标记）；真实证据见 tests/p1-phoneme.test.ts、tests/qixuan-p1-real.test.mjs 与迭代日志 2026-11-07 条目。
6. 不支持清单（UI 不得出现开关）：ene、tenc、换气声、voiceColor、phonemeEnvelope；以 `capabilities.unsupported` 为准。
