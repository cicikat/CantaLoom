Owner：Toge（toge / Frontend / UX）。状态：实现与 Mock 回归完成，待 toge 在自己的浏览器连续滚动核对手感（2026-11-08）。
范围：`src/components/ChapterActs.tsx`、`src/components/chapter-motion.ts`、`src/chapters.css`、`src/App.tsx` 的章节结构与导航滚动目标、`tests/chapter-motion.test.ts`、`tests/browser/mock.spec.ts` 中受影响的两处断言。删除被取代的 `src/components/ChapterBridge.tsx`。
依赖：toge 本轮明确要求重新设计首页、工作台与 MV 之间的滚动转场。此工单不授权修改后端、音乐算法、共享契约、`src/visual.ts` 画面或导出链路。上次方案（被回退的 43359f7）的教训：不在可操作内容上叠遮罩、不为过渡加空白、每帧只动少量元素的位移与透明度、交付前真实连续滚动。

## 设计要求（toge 原话要点）

- 五个全屏章节：首页 → 工作台文字过渡页 → 音乐积木工作台 → MV 文字过渡页 → MV，滚动依次进入，向上滚动自然返回，有连续的视觉叙事。
- 第一段：文字与背景色块随滚动产生层次变化；进入工作台时前景色块像幕布一样向下抽开，露出下层完整工作台；有遮挡、揭示和空间层次，不用淡入淡出。工作台背景色与整体设计协调，并与过渡色块自然衔接。
- 第二段：「Let's go together」逐字翻转成「Let's make a music video」，保留 Let's；字母像鼓一样滚动、模糊溶解、放大后落下、小弹跳入位。文字放在彩色背景块上，背景块随文字实际宽度平滑伸缩并与字母同步；文字与背景块对比足够。文字变化后用与前一段呼应的方式揭示 MV。
- 滚动进度驱动关键转场，一次滚轮不能跳过动画；支持反向滚动，不因重复触发闪烁、错位或布局跳动；有节奏感和趣味性。
- 2026-11-08 最新补充：四段页面转场（首页 → Music Blocks、Music Blocks → 工作台、工作台 → Let's、Let's → MV）均改为下滑触发后自动播放并落到下一页，不依赖持续滚动；内容页内仍正常滚动。
- 2026-11-08 停留方式确认：工作台是可操作内容页，不是全流程自动播放的一部分。toge 选择「滚到底后停住，再下滑一次才离开」；到达边界的那次滚动及其惯性不能同时触发离开。
